# Smart Parking Management System

A web-based parking reservation and management system developed to manage
parking slots, vehicles, reservations, payments and related parking operations.

## Project Overview

This system was developed as a database-focused university project.
It provides separate functions for users and administrators to manage
parking reservations and related activities.

## Main Features

- User registration and login
- Vehicle management
- Parking slot management
- Parking reservations
- Reservation conflict checking
- Payment management
- Fine management
- Admin dashboard
- User dashboard

## Technologies Used

- PHP
- MariaDB / MySQL
- HTML
- CSS
- JavaScript
- XAMPP

## Development Environment

- PHP 8.2
- MariaDB
- XAMPP
- Web Browser

## Project Status

Completed and tested locally using XAMPP.

This project is not currently hosted online.
